# Tdyssey 字母推动世界模型

这是截至 **2026-11-02** 的源码归档：核心代码、历次可用实验源码、配置、诊断和负结果已分类整理，并作为 Tdyssey 的 `world-model/` 独立目录维护。命令均从此目录运行。

模型用历史 RGB 和连续动作预测推动字母的下一帧。当前重点是 GPC 原生 96×96 RGB 世界模型；原官方 PushT 策略、早期自定义模型和 DPPO 工作作为独立谱系保留。

2026-11-03：交互 app 已按你的选择改为默认 **HMF500**，适合当前的 1/4 步预测使用；权重从原目录读取，不复制进 Git。启动和外部资产配置见 [app 说明](apps/r3b-playground/README.md)。

## 整理原则

- 没有把不同工作目录中同名但不同版本的代码强行合并；旧版本和各自环境锁保存在独立 profile 中。
- 历史实验的数值公式和科学设置没有因整理而主动改写。机器绝对路径及聊天标识进行了公开化替换，原始和整理后哈希分别记录。
- 重复源码保留一份，并在每个实验的 `SOURCE_INDEX.json` 中保留引用。上游原样代码以固定 commit 和来源引用保留，不复制第三方仓库的 `.git`、缓存或权重。
- 数据集、模型/优化器权重、逐帧预测、原始视频、虚拟环境、聊天内容和本机任务回执没有放入待上传目录。配置和有界摘要仍保留；外部依赖有索引。
- 已删除、无法从本地文件复核的旧尝试明确标为缺失或仅历史记录。整理源码不等于重新验证模型，也不代表实验达标。

源码整理与本次仓库集成没有训练、改物理、扩采或部署。许可证和作者署名需要由项目权利人审查确认，当前没有擅自改成 MIT/Apache。
