## 人类关于训练长度的纠正

用户明确要求查清“训练不够还是去噪采样”，300更新只建立训练链和早期学习信号。R2C2仅检验固定300更新权重的采样步数效应，不能证明训练充分、收敛、模型能力上限或继续训练无用，也不能把两个潜在因素说成唯一二选一。当前证据仅是更多原生生成迭代在这些固定窗口未解决整体形状/静止问题。

R2C3仍为准备提案，未在本阶段执行：恢复同一300更新完整状态，在1000/3000/6000观察点固定比较3/16，观察纵向训练变化与横向采样变化。应保持数据、原生损失和采样配比不变；最终下一阶段由父对话安排，不自动续训。人类纠正原文和完整边界见../PARENT_TRAINING_LENGTH_NOTE.md。
