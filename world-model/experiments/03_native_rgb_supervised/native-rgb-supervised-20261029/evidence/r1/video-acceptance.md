# R2 真实连续采样视频验收规格（方案，尚未执行）

本文件只定义后续验收。R1 没有新采样、渲染或视频；R2 仍须父对话明确放行。建议新增控制上限 ≤2000，初始化拒绝、失败、穿透早停与重放均入请求/账本；不自动支取旧余 320。旧监督采集 39680 控制、含历史 74240 控制保持不变。机器可读规格为同目录 `video-acceptance.json`。

## 时间与原始像素

每个预测/控制步真实为 **0.1 秒**，内部 10×0.01 秒物理子步。视频正常 **10fps、1×真实时间**，连续 frame i 对应 `state[i]`，PTS=`i/10` 秒。N 个完成控制保留 N+1 张原始状态帧；物理跨度 N/10 秒。固定 10fps 容器若让最后端点额外显示 0.1 秒，必须明确标注“最终端点停留”，分别报告物理跨度和容器时长，不把停留当运动。不能用更多控制拼成一个 H1，也不能跳过静止帧来放大速度。

每槽保留无覆盖文字的 **96×96 原始 RGB** 帧/视频，以及旁列明确标记的 6×最近邻显示放大（576×576）。标注“仅显示放大6×；原始图像96×96；1×真实时间”。文字和曲线放在原始图像区域外；原像素不重绘、不锐化、不去噪、不对齐、不裁物体。禁止插帧、光流/生成中间帧、改速、删静止/接近/失败帧、跨轨迹拼接或以高分辨率重绘代替原生 96px 输入。

原始完整逐帧文件仍是证据；压缩显示视频不得成为唯一来源。只允许轨迹开始时初始化，一旦中途 reset 必须明确新槽/新片，不能连续呈现成一条物理轨迹。

## 每帧/每控制必须关联的数值

| 显示或旁列字段 | 固定含义 |
|---|---|
| 槽、轨迹、字母、协议/初始状态 SHA | 能回到冻结请求和实际原始 NPZ/JSON；配对场景保存相同初始状态证据 |
| 帧号、状态索引、控制索引、模拟秒数 | 初始帧无前一转移，接触/位移显示“初始帧/不适用”，不能伪造测量 |
| action[t] 的绝对 XY、距当前 pusher 的距离、阶段 | `action[t]` 作用于 `state[t]→state[t+1]`；在到达帧标注“上一控制”，不能混淆下一动作 |
| 真实面积质心 Δx/Δy/范数（world px 与 96px 图像 px） | `origin+R*c_area`，比例 96/512；T 的物理质量中心另外列出，不能把 origin 或可见灰掩码质心冒充 COM |
| 未取模角度、每步带符号/绝对 Δθ、累计角度 | 明确单位°；累计路径/端点位移分列，不能用累计数代替单步幅度 |
| 真实 pusher-object 接触、点数、实际弧段、实际角度 | 取 arbiter 观测；同一点的 100Hz 重复计数不是独立接触段/轨迹；计划 target 不是命中 |
| 四个真实带符号墙间隙与最小的两个“墙名+间隙” | 依每个状态的旋转后几何到内壁 7/504 计算；保留负值及 gap band，初始 location 单列 |
| 每对碰撞 10 子步最大穿透、valid/失败/恢复事件 | 原 2px 子步阈值不变；不截掉负间隙或越阈数据 |

如果没有实际 wall arbiter 证据，必须标“墙挡代理/observed stall”，不能把 `near_static+contact+gap≤2` 写成已经证明的墙碰撞因果。若后续获批新增墙接触日志，只改审计记录并固定源码身份，不能借机改碰撞规律。

## 预期过程清单：覆盖实际发生的过程

按事先冻结的槽顺序列出全部实际结果，类别索引选该顺序第一个符合者并链接其他全部符合/失败槽，不按最大位移或最好外观挑片。每类至少有真实独立轨迹支持；不支持时写缺失及原因，不能自动换 seed 补到成功。

| 类别 | 必须展示的实际证据 |
|---|---|
| 平移主导 | 连续接近→接触→推移→释放，单个 0.1 秒的面积质心位移和角度同时显示；不能把“主导”写成无旋转的纯平移 |
| 旋转主导 | 偏心实际接触、接触弧段/力臂和 Δθ，同时保留平移分量 |
| 平移与旋转混合 | 两条独立幅度曲线，不能仅显示 moving 比例 |
| 边界进入 | 实际指定墙间隙持续减小，含相关接触与动作 |
| 沿墙 | 实际切向运动与墙间隙过程；计划 tangent 标签不足 |
| 离墙/退出 | 实际间隙增加，连续合法撤离或重新接触 |
| 四墙/四角与双墙过程 | 全请求/全控制的实际分母，四个带符号 gap；角落两墙各自间隙，不把初始 corner 标签当过程覆盖 |
| 受阻/停滞 | 真实接触、持续小运动、实际 gap 和动作方向；无墙接触日志时明确只能代理判断 |
| 小运动/无接触负例 | 保留接近、失去接触、非接触与目标未命中，不因“不好看”而删除 |
| 物理/恢复失败 | 每个实际失败槽的完整已记录部分和原因；若零失败如实报 0，不虚构失败片段 |

拟检验的视觉幅度目标是**每个 0.1 秒**平移 2–4 图像 px、较大平移 4–8 px，以及转角 5–15°。这些只是待检验的设计目标，在当前物理协议下尚未证实可达；现有亚像素转移不能改名称冒充大平移。若安全实现不了，应报告实际幅度上界和缺层，交父对话选择是否采用独立新协议/时间尺度，不能暗改力、阻尼、质量、速度、dt 或门槛。

真实接触覆盖仍按 8 world px 弧长分段，同时列独立轨迹、真实 contact controls、100Hz 点数、请求法向/斜推/切向与左右符号、实际相对速度角度、偏心力臂、滑动/失联/重接触。重复压同一段不能增加 unique H。封闭洞、证实不可达、未确认可达保持分开；不得传送进孔。

## 全槽分母、曲线与文件

必须交付全部计划槽表：计划、初始化拒绝、实际尝试、完成、无效、早停、重放、视频可用/缺失、实际类别支持/缺层原因。包括所有失败与静止，按字母、实际墙/角/间隙分别汇总。任何额外尝试/重放都按同一上限计费，不以视频缺层为理由自动重采。

预期目录清单（R2 放行后才生成）：

- `requests-and-budget-frozen.json`、`all-slots-index.csv`、`all-slots-summary.json`：冻结计划与全部实际槽。
- `raw-frames/slot-*/manifest.json`：全部 N+1 张原始 96px 帧及 SHA、state index、时间戳。
- `videos/slot-*-native96-1x.*` 与 `videos/slot-*-96-and-6x-annotated-1x.*`：每槽不剪辑版本；不完整失败也保留。
- `curves/slot-*.csv/png`：同一时间轴的图像位移、带符号/绝对角度、四墙/双墙 gap、接触弧段/恢复阶段、最大穿透和固定 2px 线；路径长度与端点位移分列。
- `category-index.csv`：上述全部类别的实际支持及所有缺失，不替换失败。
- `physical-quality-audit.json`：10 子步证据、固定阈值及失败。
- `video-manifest.json`：原始 NPZ/metadata/source/protocol SHA、fps/放大/插值/codec、真实跨度/容器时长、文件 SHA。
- `VIDEO_REVIEW.md`：事实分布、最小独立支持、目标未达原因与验收结论。

原始 RGB 未压缩体积为 `3*96*96*(总完成控制+实际轨迹数)` 字节，另有编码视频/曲线；R2 执行前需按当时余量锁定报告产物上限，继续共用原 3GiB 限额，不能删除旧权重/失败证据来换空间。

## 训练与模型展示边界

R2 此时只展示真实物理过程，不生成模型预测。未来获批的模型主图严格分列“**输入图像 / 真实下一帧 / 当前微调模型预测**”（H4 写“真实第4帧”）；错误颜色的原始 baseline 在单独页面写“**原始GPC（未微调，错误颜色基线）**”。不修颜色、不修图、不把 baseline 当 TRAIN 数据，不把缺测预测放进图中冒充已生成。

提交 R2 后先由父对话验收实际幅度、接触/边界覆盖、2px 物理质量和 1×视频。moving 比例、70% 重抽样或 loss 下降不能代替验收。即使视频通过，也不能自动进入正式采集或训练；后续仍需重新设计/冻结 TRAIN 与独立验证并另行放行。
