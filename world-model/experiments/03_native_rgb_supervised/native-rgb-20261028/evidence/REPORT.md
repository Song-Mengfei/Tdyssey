# 原版 GPC RGB 本地实验结果（2026-10-29）

**结论：工程与数据检查通过，物体运动预测未达标；停止扩大训练。**

本轮使用原版完整 GPC96、原始发布权重和原生 H1 残差损失，优化全部 8,729,827 个参数。输入仅含四帧 RGB 和对齐动作；没有位姿头、字母 ID、几何损失、模板搬运或输出修复。离线配准仅用于测量同一批原始预测。

## 数据、覆盖与隔离

实际518条独立轨迹、33,144个控制步（训练26,232；验证6,912），另1,416探针控制；总计34,560，额度已用完。哈希绑定物理审计通过，0非法转移。轨迹/场景分割；训练ABCEFHIJLMOPSTUVXY，DGKNQRWZ无本地预测。T在原始预训练中已见，不能称完全未见。历史项目探索也不能抹去；本轮全字母保留只描述本轮训练暴露。

控制器明确改为有限力动态推杆，保留对象几何/质量/惯性及墙体，不宣称与原始运动学控制器等价。白底、灰对象、蓝推杆，无绿色目标；红十字仅在未实跑的查看器UI上。

训练的规范可达轮廓命中率最低97.5%，总轮廓覆盖仅47.3–92.5%。将实际碰撞命中纳入“已知可达”的保守下界后，训练命中率97.78–100%，验证24.62–68.75%；仍有训练272、验证319个轮廓段可达性未确认。不能把未确认都说成不可达。518条轨迹都发生对象碰撞；14次计划轮廓目标未命中，分别O的55段6次、P的55段8次。墙/角统计是包围盒接近度，不是已保存的墙接触仲裁计数。
