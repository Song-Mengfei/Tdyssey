# 已见字母验证：负结果诊断

本次未证明世界模型优于保持最后一帧，也未通过保持形状的要求。诊断只读取已有432行RGB评分及432行物理评分，没有重跑模型、重新校准或增加控制。

- 18个已见字母各4个固定窗口，合计72个场景，H1/H4复用同一场景前缀。8个留出字母未在本地评测。
- 微调模型物理位置误差均值H1/H4为1.628/3.487世界像素，hold为0.793/2.731；物理运动综合误差为2.671/5.764，hold为1.217/4.279。微调各71/72窗口可测，hold均72/72；数值均为可测条件统计，缺测仍保留在门槛分母。
- 可见mask评分曾显示H1旋转组39.6%、H4接触/旋转组21.9%/39.0%改善；同raw的遮挡感知、对称等价物理评分全部未改善。H4配对接触误差9.249→10.631，旋转13.150→13.881。可见角度中存在H/I/O/S/X等接近180°的对称分支跳变，不能据其宣布动力学提升。
- 形状可判窗口H1为35/72，其中2个超出冻结容差（C、S）；H4为37/72，其中10个超出（C、I、J×2、O、S、V、X×2、Y）。这些失败以灰色mask面积/轮廓侵蚀为主；可判失败行未观察到新增碎片或孔洞计数改变。其余遮挡/裁边不可判行不能算形状保持通过。
- 物理评分额外保留两项不可测：F的H1蓝pusher检测失败；J的H4形状fit IoU0.665、可见缺块比例0.272。trace无丢弃、无instrumentation错误；这些不是缓存导致的缺测。
- 冻结原权重在本领域下仅H1的23/72、H4的1/72窗口满足RGB/可分割目标合约，物理位姿0/72可测。微调显著改善可用图像与轮廓，但该比较不能替代对hold的动力学优势；不应把未知幅度的RGB范围违规称为数值爆炸。

抽样限制很强：H1/H4静止窗口为51/49个，boundary均54个，boundary中分别51/49个同时静止；真实位移、旋转的中位数均为0。只有12/22个旋转窗口，且各组相互重叠。每字母4例与单训练seed不支持显著性或稳定排名：H1全部18字母的物理综合误差均值均高于hold；H4只有J条件均值较低，但J恰有一个不可测困难窗口，不能据此声称该字母成功。

训练已确认可达的规范轮廓段最低覆盖97.5%，仍有缺口；seen_val最低24.6%，另有保守未确认的可达性状态，scientific_coverage_complete=false。该覆盖不是全部姿态/接触的全覆盖保证。验证还参与checkpoint的去噪损失选择；T已在原始预训练中见过。当前结论仅为这次有界、单seed、已见字母小样本未达标，不能外推为未见字母已经失败或原生GPC方法不可能。
