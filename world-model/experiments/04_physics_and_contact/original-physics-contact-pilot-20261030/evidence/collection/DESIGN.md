Existing complete slots are referenced, not rerun; incomplete claims stop for owner audit. Reports never reconstruct labels from seeds or remove bad frames.

Full uncompressed RGB primary payload~647MB, but sparse white/gray/blue PNG-like NPZ compression avoids full PNG dumps. Resource checks use actual files and preserve prior output on a storage stop. All attempts, all valid physical time and final complete candidate windows are separate denominators. Contacts use actual post-solve pairs weighted by actual dt. AO, OW-only, AO with/without real motion, search, noncontact-static, post-release motion and invalid classes stay separate. Numerical movement floor=.1imagepx or.1degree per.1s, linearly dt-scaled for microstep-time statistics. It is a label threshold, not a visual success rule. Raw values/quantiles/histograms remain available. Same arbiter impulse is not summed once per point. Arc-time is counted once per observed arc/microstep.

Saved-only HTML/CSV/JSON report includes every attempt and split; per-letter/contact-phase/boundary H1/H4 P10/P50/P90/P95/max, bins, net versus cumulative movement, contact/invalid/intervention denominators and actual exterior/hole projection coverage. Each letter has selected translation/rotation/boundary examples, a fixed-seed complete random sample and a weak-motion sample; rejected cases are linked when present. Labels disclose a final0.1s endpoint hold. If a required motion example is missing, report it rather than invent it.
