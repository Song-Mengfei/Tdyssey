% Architecture experiment (deck slide "Does the network matter?"): the official Diffusion Policy network of the main
% model against Flow-DiT, a 505M flow-matching transformer policy, same input, same training data, same output.
% Facts: docs/DECISIONS.md D059, D061, D064 (scripts/learning/flow_policy.py, runs/flow26b16): DINOv2 ViT-B/14 encoder
% (86.6M, pretrained on ordinary photos, fine-tuned), each 96 px frame cropped to 84 px and enlarged to 224 px, all
% 16x16 patch tokens + CLS per frame (no pooling) plus one pusher token; DiT action head 418.2M (24 blocks, the 16 action
% tokens attend to each other and to the image and pusher tokens, denoising time enters every block), flow matching,
% 10 sampling steps; 504.8M in all; 160k training steps from scratch, no correction rounds of its own. Official network: ResNet-18 encoder (11M) and
% 1D U-Net (251M), diffusion with 100 denoising steps.
